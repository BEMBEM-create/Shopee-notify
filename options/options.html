⚡ การทำงานหลัก

โหมดทำงาน: Passive interception — ดักจับ response ที่ JST เรียกเองทุก 1 นาที ต้องเปิดแท็บ JST ค้างไว้บนหน้า "คำสั่งซื้อรอจัดส่ง"

เปิดแล้วจะ replay request ที่ JST ส่งเอง (ใช้ session/cookie ของแท็บนั้น) — ไม่ใช่ reload หน้า ใช้ไม่รบกวนการใช้งาน. เพิ่ม API call ของ JST เท่าตัว ใช้เท่าที่จำเป็น
